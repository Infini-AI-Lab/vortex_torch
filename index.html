Vortex

A flexible and efficient sparse-attention framework for fast LLM decoding. Describe a flow in a few lines of Python — Vortex JIT-compiles it into fused Triton kernels that plug straight into SGLang.

JIT-compiled Triton kernels SGLang backend PyTorch-like frontend

Install

git clone --recursive https://github.com/Infini-AI-Lab/vortex_torch.git
cd vortex_torch

# SGLang dependency (vendored)
cd third_party/sglang/v0.5.9/sglang
pip install -e "python"
cd ../../../../

# Vortex
pip install -e .
